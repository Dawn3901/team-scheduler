# CR-010 日历颜色语义化与新手教程

- 状态：**用户要求 · 已实施 · 待 A/B 复核**（2026-11-11）
- 提出：产品使用反馈（用户 2026-11-11）
- 影响需求：CAL-6（颜色与图例）；新增 UX 教程（不新增 P0 编号）
- 影响代码：`apps/web/src/lib/calendarColors.ts`、`CalendarPage`、`CalendarTimeline`、`EventEditor`、`TutorialPage`、`TutorialPrompt`
- 契约影响：**无 API/DB 变更**；`events.color` 字段保留兼容，前端不再提供自定义颜色输入，日历不再按创建者/自定义色渲染。

## 1. 背景

原 CAL-6 要求“事件颜色可自定义；无自定义时按创建者颜色；图例可读”。实际使用中，用户更关心“这个活动我要不要参加”，而不是谁创建的、选了什么颜色；图例也不是刚需。用户同时提出需要一份初次使用教程。

## 2. 新规则

### 活动颜色

| 颜色 | 含义 |
|---|---|
| 蓝色 | 需要我参加：我是组织者或参与者，且未拒绝 |
| 绿色 | 不需要我参加：团队活动但我未被邀请，或我已拒绝 |
| 灰色 | 私密活动（仅组织者/参与者可见详情） |

### 任务截止颜色

| 颜色 | 含义 |
|---|---|
| 红色 | 已逾期，或 24 小时内截止 |
| 黄色 | 24–72 小时内截止 |
| 白色 | 正常（>72 小时）或已完成 |

- 不再要求“按创建者色”或“自定义颜色”；活动编辑器的颜色输入移除。
- 不新增日历图例；颜色含义写进新手教程与用户手册。
- 新增 `/app/tutorial` 教程页；首次进入团队选择页显示可关闭提示，用户可“开始教程”或“不再提示”。
- 教程覆盖：团队/邀请码、日历颜色、活动与 RSVP、忙闲/冲突、任务、通知与三端。

## 3. 验收标准

- 活动列表/月周日视图：组织者/未拒绝参与者为蓝，未邀请/已拒绝为绿，私密为灰。
- 任务截止：逾期/24h 内红，24–72h 黄，其余白；已完成白。
- 新建/编辑活动不再显示颜色选择；保存不因缺少 color 失败。
- 新手教程可从侧栏进入；首次进入团队选择页有提示；点击开始/不再提示后不重复出现。
- 教程和用户手册包含颜色速查表。
- Web 单测、typecheck、lint、E2E 通过。

## 4. 兼容与限制

- `events.color` 仍可读写（旧数据/API 客户端兼容），但日历不展示自定义色；后续如要恢复“自定义色”需另立 CR。
- 颜色仅表达“是否需要处理”，不表达优先级；P0 任务仍按逾期/截止时间计算。
- 时间轴背景是 10% 浅色，统一用深色文字（`#111827`）；月/周视图的实心色块仍按背景明暗选择黑/白文字。
- 首次提示使用 `localStorage["teamsync.tutorial.seen"]`；换设备/清缓存会再次出现。
- 本 CR 由用户提出并确认方向；A/B 复核签字栏留空。
