# ADR-005：AI 只读上下文与活动草稿确认

日期：2026-11-16。状态：按用户明确要求实现，待项目成员评审。

采用服务端 Chat Completions JSON 输出，使用标准库 HTTP 客户端，兼容 DeepSeek。模型只能获得经既有权限/私密规则过滤的团队上下文；服务端对结构、时间、成员重新校验。浏览器通过 shared API 获取回复，不接触供应商密钥。

选择活动草稿确认而非给模型数据库写工具：用户可以核对解析结果，既有创建接口继续承担事务、冲突、通知与邀请逻辑，避免聊天重试或伪造“确认”历史直接修改数据。草稿不持久化，不新增迁移。模型可能产生错误或受数据文本影响，所有展示按普通文本渲染，不执行HTML/Markdown链接/脚本，不提供任意工具执行能力。

替代方案：新增OpenAI SDK（本次不需要依赖）；浏览器直连（暴露密钥，放弃）；模型自动创建（缺乏具体结果核对，放弃）；持久聊天表（超出此次需求，放弃）。

代价：每次发送携带有限上下文；不提供超出范围的检索、不保存聊天。实际创建仍需要点击一次确认。供应商不可用时显示可恢复错误，现有手动创建入口保持可用。
