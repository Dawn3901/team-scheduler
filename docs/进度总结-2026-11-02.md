### 8000 端口占用

本聊天中曾由助手先启动后端，随后在用户终端重复执行 `make dev-api`，出现：

```text
ERROR: [Errno 98] Address already in use
```

这表示 8000 端口已有进程监听，不代表本次实现无法启动。先访问 `/health` 和 `/docs`：如果能正常打开，直接使用已有服务即可。

需要自己管理启动时，在原启动终端按 `Ctrl+C` 停止旧服务，再运行 `make dev-api`。不确定占用者时先查询，不要直接结束未知进程：

```bash
ss -ltnp 'sport = :8000'
```

如需临时另开端口：

```bash
cd server
.venv/bin/python -m uvicorn app.main:app --reload --port 8001
```

此时接口文档为 `http://127.0.0.1:8001/docs`；Web 默认仍代理 8000，如切换后端端口，需要在启动 Web 时设置 `VITE_API_TARGET=http://127.0.0.1:8001`。
