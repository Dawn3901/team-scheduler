# TeamSync 已知限制（W5-07）

> 日期：2026-11-11。本文记录“当前版本确实没做/没验证”的内容，避免答辩时把计划当成已完成。

## 1. 产品范围

- 不做离线写入；服务器是唯一数据源，断网只能只读/等待恢复。
- 不做后台推送；Android 只有本地定时通知，应用被杀死后不能实时接收服务端变更。
- 不做 IM、视频会议、附件、评论、多日历、企业级权限体系、排班考勤。
- 不做无限重复/复杂 RRULE；重复活动只支持每周/每双周、次数或结束日期（最多 52 次/一年内）。
- 不做个人日历（CR-002 尚未开始）、外部 ICS 导入、Quick Add。
- 不做邮件提醒；只有站内通知、桌面系统通知、Android 本地通知。

## 2. 三端

- **Web**：功能最全；移动端浏览器可用，但未做原生 App 级手势/键盘适配。
- **Electron**：当前是开发壳；`app://` 构建模式没有 `/api` 代理，登录/实时通知要用 Vite 5173 + `--web-url`。`electron-builder`/Windows 安装包尚未接入。
- **Android**：原生 Kotlin WebView 壳；W4 本地通知代码尚未在 JDK/Android SDK 环境编译，未真机验证；与 `docs/00` 的 Capacitor 基线不一致，见 [ADR-003](changes/ADR-003-实现现状与冻结基线差异.md)。
- Android 12+ 精确闹钟权限未授权时，提醒会降级为非精确；系统省电策略也可能延迟。
- 应用被系统杀死后，已排本地通知仍可能触发，但服务端新变更不会实时到达。

## 3. 部署与运维

- 单进程、SQLite；不支持多 worker、多实例、PostgreSQL 生产部署。
- 当前提供单进程静态托管（`SERVE_WEB=1`）和 Nginx 配置示例；W5-05 已由用户验证通过，HTTPS/防火墙仍需按现场环境确认。
- 静态托管模式未内置 HTTPS；生产需在反向代理层配置 TLS。
- 数据库备份为 SQLite 文件/在线备份；未做跨机器复制/对象存储。
- 演示种子为 3 账号 + 5 活动 + **2 个任务**（计划旧稿的 5 个任务已废止）。

## 4. 安全与性能

- 登录限流（AUTH-7 / SEC-09，429）仍是 P1，尚未实现；当前只有错误码预留。
- JWT 存 localStorage，依赖 CSP + React 转义缓解 XSS；httpOnly cookie 仍是 P1。
- 没有企业级审计、登录历史、设备管理。
- 性能：本机 50 用户/1 万活动/5000 任务基准中，31 天活动查询约 110ms、7 天忙闲查询约 3.0s、任务首页约 89ms；忙闲是明显瓶颈，未做分页/缓存/索引优化。
- 大公司模拟的 5000 节点依赖图约 6.5s，存在 N+1；只适合演示，不代表容量承诺。

## 5. 测试与验收

- 后端 145 条、Web 49 条、shared 22 条、Playwright 19 条于 2026-11-11 通过；E2E 尚未接入 CI。
- Android 真机/模拟器、Windows 安装包、HTTPS 未验证；W5-05 局域网部署已由用户确认。
- W5-06 UI 走查已由用户确认通过；弹窗焦点陷阱、颜色对比、真机键盘仍记为 P1。
- W5-08/G5 需要 A/B 两人签字；本仓库的 AI 记录不能代替验收。
