# TeamSync 部署文档（W5-05）

> 适用：课程演示的**单机 / 局域网**部署。默认 Windows，Linux/WSL 命令在括号里注明。
> 方案：一个 FastAPI 进程同时提供 Web 静态文件、HTTP API 与 WebSocket，SQLite 单文件。

## 1. 前置条件

- Python 3.12/3.13，已执行 `make setup`，`server/.venv` 可用。
- Node 22 + pnpm 12，已执行 `pnpm install`。
- 演示机与访问设备在同一局域网；Windows 防火墙放行 8000 端口。

## 2. 构建与初始化

```powershell
cd E:\My_Files\SomethingInteresting\team-scheduler

# 1) 构建 Web（必须先生成 apps/web/dist）
pnpm --filter @teamsync/web build

# 2) 迁移 + 演示种子
cd server
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m app.seed
```

Linux/WSL 把 `.\.venv\Scripts\python.exe` 换成 `./.venv/bin/python`。

## 3. 配置

根目录 `.env` 至少确认：

```dotenv
SECRET_KEY=<随机长字符串>
DATABASE_URL=sqlite:///./data/teamsync.db
SEED_PASSWORD=<演示密码>
SERVE_WEB=1
# 可选：自定义 Web 构建目录；默认 <repo>/apps/web/dist
# WEB_DIST=apps/web/dist
```

- `SERVE_WEB=1` 才会由 FastAPI 托管 `apps/web/dist`；默认关闭，开发仍用 Vite 5173。
- 同源部署时不需要把局域网 IP 加进 `CORS_ORIGINS`；如果前后端分域，再配置白名单。
- 不要把 `.env` 提交到仓库。

## 4. 启动

```powershell
cd server
$env:SERVE_WEB="1"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1
```

Linux/WSL：

```bash
cd server
SERVE_WEB=1 ./.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1
```

访问：

- 本机：<http://127.0.0.1:8000>
- 局域网：`http://<本机局域网 IP>:8000`
- 查 IP：Windows `ipconfig`，Linux `ip addr`。

## 5. 启动后自检

```powershell
curl http://127.0.0.1:8000/health
# {"status":"ok","db":"ok"}

curl -o NUL -w "%{http_code}" http://127.0.0.1:8000/
# 200，返回 Web HTML

curl -o NUL -w "%{http_code}" http://127.0.0.1:8000/app/teams/1/calendar
# 200，SPA 回退到 index.html

curl -o NUL -w "%{http_code}" http://127.0.0.1:8000/assets/<构建产物>.js
# 200，application/javascript
```

WebSocket 与 API 同源，浏览器会连 `ws://<host>:8000/api/v1/ws`，不需要额外端口。

## 6. 备份与恢复

- 在线备份由 `server/app/scheduler/backup.py` 每日生成，目录 `server/data/backups/`，保留最近 7 份。
- 手动备份（停服务后）：

```powershell
Copy-Item server\data\teamsync.db server\data\backups\before-upgrade.db
```

- 恢复：

```powershell
# 停服务
Copy-Item server\data\backups\before-upgrade.db server\data\teamsync.db -Force
cd server
.\.venv\Scripts\python.exe -m alembic upgrade head
# 启动
```

## 7. 升级

```powershell
# 1) 停服务
# 2) 备份 server\data\teamsync.db
# 3) 拉代码、安装依赖
pnpm -r typecheck
cd server
.\.venv\Scripts\python.exe -m alembic upgrade head
# 4) 重新构建 Web 后启动
pnpm --filter @teamsync/web build
```

迁移前先看 `alembic current` 是否为 `98643d74e9bb (head)`；不一致时不要启动服务。

## 8. 可选：Nginx 反向代理

如果不用 FastAPI 托管静态文件，可设 `SERVE_WEB=0`，由 Nginx 提供 `apps/web/dist`，并反代：

```nginx
server {
  listen 80;
  server_name _;
  root /path/to/apps/web/dist;
  index index.html;

  location /api/ { proxy_pass http://127.0.0.1:8000; proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; }
  location /health { proxy_pass http://127.0.0.1:8000; }
  location / { try_files $uri /index.html; }
}
```

生产环境在反向代理层启用 HTTPS；FastAPI 仍只监听 8000，`--workers 1`。

## 9. 已验证范围（2026-11-11）

在本机 `127.0.0.1:8020` 以 `SERVE_WEB=1` 启动真实 uvicorn：

- `/` 200 HTML，CSP 为 Web 版本；
- `/app/teams/1/calendar` 200，SPA 回退；
- `/assets/*.js` 200，`application/javascript`；
- `/api/v1/nope` 404，不会被 SPA 吞掉；
- `/health` 200，CSP 为 API 版本；
- 登录后 WebSocket `ws://127.0.0.1:8020/api/v1/ws` 收到 `connected`。

**未验证**：局域网另一台设备、Windows 防火墙实际放行、HTTPS。需要演示前人工补。

## 10. 已知限制

- 单进程、SQLite；不支持多 worker / 多实例。
- 不做离线写；不做后台推送。
- Android 端仍需本机 WebView 壳与通知权限；见 [已知限制](已知限制.md)。
- 当前 Electron 打包模式（`app://`）没有 API 代理，演示桌面端用 Vite 5173 + `--web-url`；见 [W4 记录](dev/12-W4-三端通知与联调-2026-11-11.md)。
