# TeamSync 用户手册（W5-07）

> 完整功能与常见问题见根目录 [README](../README.md)；这里给第一次使用者的最短上手路径。

## 1. 注册与登录

1. 打开 Web 地址（本地开发 `http://127.0.0.1:5173`，部署后 `http://<服务器>:8000`）。
2. 点“注册”，填用户名、显示名、密码。
3. 注册成功后自动登录；以后用同一用户名/密码登录。
4. 刷新页面仍保持登录；右上角/侧栏“退出”会清除登录态。

## 2. 创建团队与邀请成员

1. 登录后点“创建团队”，填团队名称。
2. 进入团队后，在侧栏/团队设置里能看到 8 位邀请码。
3. 队友注册后点“用邀请码加入”，输入邀请码即可。
4. Owner 可轮换邀请码、调整 Admin、移除成员；Admin 可管理成员；Member 参与协作。

## 3. 团队日历

- 右上角切换 **月 / 周 / 日** 视图。
- “今天”回到当天；左右箭头翻页。
- 成员筛选：全部成员 / 指定成员 / 只看我的。
- 事件颜色可按活动自定义；任务截止日显示在日历的“全天”行。

## 4. 新建活动与邀请

1. 点“新建活动”，填标题、开始/结束时间、地点、描述、颜色、可见性。
2. 邀请成员：
   - 勾选成员（复选框 + 头像 + 姓名）；
   - 点“邀请全员”一次勾选所有其他成员；
   - 全部勾选后按钮变为“取消邀请全员”，再点一次全部取消；
   - 自己不会出现在邀请列表里（组织者自动参加）。
3. 保存时如果时间冲突，会弹出冲突成员/时段；可以改时间，或“仍然创建”。
4. 按 `Esc` 可取消新建/编辑弹窗；点“取消”效果相同。

## 5. 回应邀请（RSVP）

在活动详情中：

- **接受**：确认参加；
- **待定**：暂不确定；
- **拒绝**：不参加，且不计入冲突。

组织者会自动接受，不能拒绝自己。活动时间/地点变更后，已接受/待定的成员会收到“待重新确认”。

## 6. 忙闲与冲突

- 周视图可勾选“显示周忙闲”，按成员显示忙碌块。
- 私密活动在别人的忙闲里只显示“忙碌”，不显示标题。
- 给忙碌成员建活动会出现冲突提示；冲突是警告，不是强制阻止。

## 7. 任务

1. 进入“任务看板”，点“新建任务”。
2. 填标题、描述、负责人、截止时间、优先级；可选前置任务。
3. 任务未完成且负责人是自己时，会在截止前 1 小时提醒；逾期每日 09:00 提醒。
4. 任务完成后变绿；截止日会出现在日历“全天”行。
5. 新建/编辑任务按 `Esc` 可取消。
6. 前置任务未完成时，后续任务显示“阻塞”，不能开始/完成；依赖关系可看“依赖关系图”。

## 8. 通知与提醒

- 侧栏/顶栏铃铛显示未读数；通知中心可“仅未读”“全部已读”，点击通知跳到活动/任务。
- Web 显示站内 toast；Electron 桌面端弹系统通知；Android 用本地定时通知。
- 事件开始前 15 分钟、任务截止前 1 小时；同一提醒不会重复弹。
- 桌面端关闭窗口会隐藏到托盘，托盘菜单可退出。

## 9. Android

- 安装 debug APK 后登录；首次进入团队会请求通知权限。
- Android 12+ 还需要在系统设置允许“闹钟和提醒”，否则提醒可能延迟。
- 本地通知只排未来 7 天；修改活动后会重排；点击通知打开对应活动/任务。
- 不做后台推送；应用被系统限制时，通知可能延迟。

## 10. 使用限制

- 服务器权威，不做离线写入。
- 不做 IM、视频会议、多日历、企业权限、附件/评论。
- 私密活动只有组织者和参与者能看详情；非参与者在忙闲里只看到“忙碌”。
- 详细限制见 [已知限制](已知限制.md)。
