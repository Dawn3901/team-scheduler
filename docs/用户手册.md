# TeamSync 用户手册（W5-07）

> 完整功能与常见问题见根目录 [README](../README.md)；这里给第一次使用者的最短上手路径。

## 1. 注册与登录

1. 打开 Web 地址（本地开发 `http://127.0.0.1:5173`，部署后 `http://<服务器>:8000`）。
2. 点“注册”，填用户名、显示名、密码。
3. 注册成功后自动登录；以后用同一用户名/密码登录。
4. 刷新页面仍保持登录；右上角/侧栏“退出”会清除登录态。

## 2. 创建团队与邀请成员

1. 登录后点“创建团队”，填团队名称。
2. 进入团队后，在侧栏/团队设置里能看到 8 位邀请码。
3. 队友注册后点“用邀请码加入”，输入邀请码即可。
4. Owner 可轮换邀请码、调整 Admin、移除成员；Admin 可管理成员；Member 参与协作。

## 3. 团队日历

- 右上角切换 **月 / 周 / 日** 视图。
- “今天”回到当天；左右箭头翻页。
- 成员筛选：全部成员 / 指定成员 / 只看我的。
- 任务截止日显示在日历的“全天”行。
- 第一次使用可点侧栏 **新手教程**，或按首次进入时的提示查看。
- 想了解产品定位、功能与边界，点侧栏 **关于**（`/app/about`）；页面底部有**版本号、提交号与构建时间**，演示排障时先核对这三项。

### 3.1 颜色怎么读

| 颜色 | 含义 |
|---|---|
| 蓝色活动 | 需要我参加（我是组织者/参与者，且未拒绝）；我自己创建/参与的私密活动也是蓝色 |
| 绿色活动 | 不需要我参加（团队活动但未邀请我，或我已拒绝） |
| 灰色活动 | 别人的私密活动：你只能看到忙碌，看不到标题 |
| 红色任务 | 已逾期，或 24 小时内截止 |
| 黄色任务 | 24–72 小时内截止 |
| 白色任务 | 正常（>72 小时）或已完成 |

颜色只表示“我要不要处理”，不表示创建者；活动编辑器不再提供自定义颜色。完整教程见侧栏“新手教程”或 `/app/tutorial`。

## 4. 新建活动与邀请

1. 点“新建活动”，填标题、开始/结束时间、地点、描述、可见性。
2. 邀请成员：
   - 勾选成员（复选框 + 头像 + 姓名）；
   - 点“邀请全员”一次勾选所有其他成员；
   - 全部勾选后按钮变为“取消邀请全员”，再点一次全部取消；
   - 自己不会出现在邀请列表里（组织者自动参加）。
3. 保存时如果时间冲突，会弹出冲突成员/时段；可以改时间，或“仍然创建”。
4. 按 `Esc` 可取消新建/编辑弹窗；点“取消”效果相同。

## 5. 回应邀请（RSVP）

在活动详情中：

- **接受**：确认参加；
- **待定**：暂不确定；
- **拒绝**：不参加，且不计入冲突。

组织者会自动接受，不能拒绝自己。活动时间/地点变更后，已接受/待定的成员会收到“待重新确认”。

## 6. 忙闲与冲突

- 周视图可勾选“显示周忙闲”，按成员显示忙碌块。
- 私密活动在别人的忙闲里只显示“忙碌”，不显示标题。
- 给忙碌成员建活动会出现冲突提示；冲突是警告，不是强制阻止。

## 7. 任务

1. 进入“任务看板”，点“新建任务”。
2. 填标题、描述、负责人、截止时间、优先级；可选前置任务。
3. 任务未完成且负责人是自己时，会在截止前 1 小时提醒；逾期每日 09:00 提醒。
4. 任务完成后变绿；截止日会出现在日历“全天”行。
5. 新建/编辑任务按 `Esc` 可取消。
6. 前置任务未完成时，后续任务显示“阻塞”，不能开始/完成；依赖关系可看“依赖关系图”。

## 8. 我的日程（个人日历）

- 侧栏点 **我的日程**（`/app/me/calendar`），只显示「我的」内容：
  - 我自己建的个人日程；
  - 我在各团队里**参加或待回应**的活动（不需要我参加的团队活动不显示）；
  - 指派给我的任务（逾期或 30 天内到期）。
- 视图：**月 / 周 / 任务清单** 三选一，**没有单日视图**；视图与日期会被记住。
- 颜色（只表达要不要马上处理）：

| 颜色 | 含义 |
|---|---|
| 红 | 紧急：任务逾期或 24 小时内截止；个人日程进行中或 2 小时内开始 |
| 蓝 | 团队活动在等你回应 |
| 绿 | 正常 |

- 个人日程**默认以“忙碌”参与团队忙闲**（CR-013 起不再提供逐条关闭开关）；队友只能看到时间段，看不到标题。
- 点团队活动 → 团队活动详情；点任务 → 团队任务看板；点个人日程 → 打开编辑弹窗。
- 个人日程不产生提醒；课表导入、个人任务属于后续扩展（CR-003 / CR-005）。

## 9. 通知与提醒

- 侧栏/顶栏铃铛显示未读数；通知中心可“仅未读”“全部已读”，点击通知跳到活动/任务。
- 同一个活动被反复修改时，通知中心只显示一条“活动变更”（带 `×N` 与最近时间），点“另 N 条”可展开历史；其他类型（邀请、取消、提醒）各自成组。
- Web 显示站内 toast；Electron 桌面端弹系统通知；Android 用本地定时通知。
- 事件开始前 15 分钟、任务截止前 1 小时；同一提醒不会重复弹。
- 桌面端关闭窗口会隐藏到托盘，托盘菜单可退出。

## 9.0 团队沟通（通告 / 讨论 / 收件箱）

- **团队通告**：管理员/所有者可在侧栏“团队通告”发布，支持置顶、失效时间、以及“需要成员点我知道了”。
  成员打开后点“我知道了”才算确认；作者能看“已确认 9/12”和未确认名单。
- **通知**：侧栏只有一个“通知”入口，里面分两个标签——
  **全部动态**（默认）按对象合并展示发生过的事（邀请、改期、指派、提醒、@、新通告），可“仅显示未读”“全部已读”或展开历史；
  **待处理**汇总还没确认的通告、@我的消息、我负责/组织的活动任务里的新讨论，打开即标记已读（通告除外，必须点“我知道了”）。
  正文就是主信息，活动/任务名只是上下文。
- 发布者的通告默认已确认，不需要自己再点“我知道了”。
- **活动讨论**：活动详情底部可讨论；输入 `@` 会弹出成员候选，选中即插入并通知对方（删掉名字会取消这条提醒）。
  改期或取消时可填“变更原因”，会自动写进讨论并通知参与者。
- **新建活动**：表单里的“留言”支持 `@`，发布后会出现在活动讨论里，被 @ 的成员会收到提醒。
- **任务讨论**：任务卡片“讨论”按钮打开；可标记“受阻”并填原因（卡片会显示“受阻：等设计稿”），解除后自动收起。
  新建/改派任务时可写“要求 / 交接说明”，会写进任务讨论。
- **我的回应**：在活动详情里，自己那一行右侧直接点「接受 / 待定 / 拒绝」，当前状态高亮；别人那行只显示状态标签。
  可以在下方填“附言”（例如“我会迟到 10 分钟”），**只有组织者/管理员和你自己能看到**。
- **取消活动**：组织者/管理员在右上角点「取消活动」，确认后活动从日历消失并通知参与者；重复活动可选择取消范围。
  取消后不可恢复，创建错了也用取消并在讨论里说明即可。
- 不做自由聊天频道与私聊；要全员知道的事请发通告。

## 9.1 个人资料与头像

- 侧栏 →“个人资料”：可修改显示名、首字头像底色，并**上传头像**（JPG / PNG / WebP，不超过 2 MB）。
- 头像会出现在侧栏、顶栏、团队成员列表和日历的成员列；点“移除头像”恢复为显示名首字。
- 头像文件存在服务器 `server/data/avatars/`，随数据库一起备份；未上传时显示首字。

## 10. Android

- 安装 debug APK 后登录；首次进入团队会请求通知权限。
- Android 12+ 还需要在系统设置允许“闹钟和提醒”，否则提醒可能延迟。
- 本地通知只排未来 7 天；修改活动后会重排；点击通知打开对应活动/任务。
- 不做后台推送；应用被系统限制时，通知可能延迟。

## 11. 使用限制

- 服务器权威，不做离线写入。
- 不做 IM、视频会议、多日历、企业权限、附件/评论。
- 私密活动只有组织者和参与者能看详情；非参与者在忙闲里只看到“忙碌”。
- 详细限制见 [已知限制](已知限制.md)。
