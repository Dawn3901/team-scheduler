## 维护约定

- 不在这里复制需求/契约正文；以 [docs/02](../02-需求规格说明书.md)、[docs/03](../03-概要设计说明书.md)、[docs/ai/02](../ai/02-接口与数据契约.md) 为准，这里只做导航和开发说明。
- 新增/修改命令，同步更新本目录与根 README。
- 文档里的命令必须实际跑过；没跑过的写“未验证”，不要写“应该可以”。
- 环境相关的结论注明平台（Windows / WSL / macOS）与版本，避免把一台机器的现象当成通用事实。
