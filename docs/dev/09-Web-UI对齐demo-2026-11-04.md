## 待定：任务状态视觉（2026-11-05）

日历上原来用颜色区分任务状态：

- 灰色 = 任务截止；
- 红色 = 逾期；
- 绿色 = 已完成。

这些颜色会和活动自定义色冲突，尤其活动本身也可以是红/绿/灰色。当前先做临时处理：

- 日历上的任务截止块统一用中性 slate 色；
- 状态不再只靠颜色，标题里临时带 `（已完成）` / `（已逾期）` 文案；
- 删除了日历顶部“彩色为活动 · 灰色为任务截止…”的说明，避免把临时规则写成正式规则。

最终视觉方案**尚未确定**，候选：

1. 任务块左下角贴一个小徽标/贴纸（如“完成”“逾期”），颜色只做辅助；
2. 用图标或短标签代替整块变色；
3. 任务截止和活动使用不同形状（例如虚线边框），而不是不同颜色。

待 A/B 确认后再改；如果方案影响 `docs/02` 的视觉规则，需要同步更新验收文档。

## 日历单日视图（2026-11-05）

单日视图改成按成员分栏：

- 用 `react-big-calendar` 的 resources 模式，每个成员一列；
- 活动按参与者复制到对应成员列，任务按负责人放到对应列；
- 列头显示头像、姓名、角色；
- 列之间保留 3px 间隙，重叠的同一活动不会被画成一条横跨多列的长条；
- 周/日视图仍限制 08:00–22:00，月视图保留全天。

同时把默认工具栏换成自定义工具栏：

- 上一页 / 今天 / 下一页；
- 月 / 周 / 日分段按钮；
- 日期范围放在日历标题下，工具栏不再重复显示日期。

## 自适应时间轴（2026-11-06）

本次以远端 `feat/ui-demo-parity` 的 `fa4f925` 为基线，针对 CAL-2/3/7 调整周 / 日时间轴：

- 沿用侧栏、右侧信息卡、自定义日期导航、单日成员分栏和今天贴纸；月视图继续用原有日历组件。
- 周 / 日时间网格使用本地 React 组件呈现，共享日期工具负责团队时区与 UTC 转换，无新增依赖或 API 变更。
- 滚轮与按钮提供 2 小时、1 小时、30 分钟、15 分钟四档刻度；缩放以鼠标下的时间为锚点，不修改事件时间。
- 长空闲时段自动收起，可点击展开、重新折叠；活动、任务截止、私密忙碌和重叠活动分栏保留。
- 全天私密忙碌沿用基线处理，不铺满时间网格；任务维持中性色与状态文字。
- 可访问时间范围扩展为全天，凌晨/深夜的长空闲默认折叠，跨日事件不会被固定 08:00–22:00 裁掉。
- 这属于时间轴显示缩放，不是拖拽修改活动起止时间。

测试增加折叠/展开、滚轮粒度边界、跨午夜坐标、活动重叠和成员列隔离用例；E2E 定位同步到新时间轴，保留跨月多日、任务截止和 375px 容器横滑断言。具体执行结果见本次任务报告，不代替人工验收。
