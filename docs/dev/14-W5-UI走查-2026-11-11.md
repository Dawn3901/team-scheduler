## 2. 加载状态

- 团队/工作区：`workspace-skeleton` 骨架。
- 日历：`日历加载中…` Suspense。
- 任务/通知/成员：`加载中…` 文本。
- 保存中：按钮 `disabled` + `action.pending`。

## 3. 错误状态

- 全局 `ErrorBoundary`；请求错误走 `friendlyMessage` + toast。
- 表单 422 映射到字段错误。
- 断网：`useAction` 提示“当前离线”；WS 显示“连接已断开，正在重连…”。
- E2E 覆盖：401、错误邀请码、断网恢复、冲突 409。

## 4. 移动端 375px

- E2E 断言：页面 `scrollWidth <= innerWidth`；周视图在日历容器内横滑。
- 弹窗 `width: 560px; max-width: 100%; max-height: 92vh; overflow: auto`。
- 邀请列表一列式，复选框 + 头像 + 姓名；E2E 截图 `debug/invite-list.png`。
- 未做真机软键盘/安全区域逐项走查。

## 5. 键盘可达性

- 新建/编辑活动、新建/编辑任务支持 **Esc** 关闭（`useEscapeKey`，保存中禁用）。
- 输入框有 `<label>`；弹窗有 `role="dialog" aria-modal="true"` 与 `aria-label`。
- 邀请成员复选框有显式 `aria-label`，头像 `aria-hidden`。
- **缺口**：弹窗没有焦点陷阱（Tab 可离开弹窗）；关闭后焦点未显式回到触发按钮；颜色对比未逐项测量。这些记为 P1，不阻塞演示。

## 6. 本次发现并修正

- 邀请列表原先只有纯文本，改为复选框 + 头像 + 姓名一列式；补 `aria-label`，避免头像首字混入可访问名称。
- “邀请全员”改为可逆切换：全部选中后显示“取消邀请全员”。
- 增加 Esc 关闭；补 `useEscapeKey` 单测与两条 E2E。
- 新增 `/app/tutorial` 新手教程与首次进入提示；颜色速查见 [CR-010](../changes/CR-010-calendar-semantic-colors-and-tutorial.md)。
