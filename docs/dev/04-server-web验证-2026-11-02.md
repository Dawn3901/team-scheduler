## 可复现命令

在项目根目录：

```bash
make setup
make migrate
make seed
make dev
# 浏览器 http://127.0.0.1:5173

make check
pnpm build
PLAYWRIGHT_CHANNEL=chrome pnpm test:e2e
```

Linux 需系统 Chrome（`/opt/google/chrome/chrome`）；Windows 不设置 `PLAYWRIGHT_CHANNEL` 时使用系统 Edge。依赖须在运行平台安装。本次环境使用 `npm_config_store_dir=/tmp/teamsync-pnpm-store npm_config_verify_deps_before_run=false` 避免 sandbox 外 pnpm store 写入及自动安装。

Chrome E2E 使用 `8010/5174` 与独立 `server/data/e2e.db`，不连接日常数据库。

## 数据与服务

- 新迁移从旧 head `0002_w1_db_auth` 升级，禁止删库替代升级。
- 提醒：每 60 秒；事件开始前 15 分钟、任务前 1 小时、团队时区每天 09:00 后补发当日逾期；唯一键去重。
- 备份：服务运行时每分钟检查当天备份是否存在，SQLite backup API 生成一致性副本；路径为数据库同目录的 `backups/teamsync-YYYY-MM-DD.db`，保留七份。离线恢复时先停止服务，将目标备份复制到 `DATABASE_URL` 指向的文件，再启动；不要同时保留旧的 `-wal/-shm` 文件。
- 私密活动：自愿拒绝有 `responded_at`，仍允许重新回应；组织者移除的参与者保留 declined 行、清空回应时间，失去私密详情访问，重新邀请恢复 pending。未增加列。
- 活动取消使用既有 `PATCH /events/{id}` 的 `status=cancelled`；删除同时软删除并通知。
