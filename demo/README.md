# TeamSync 静态交互演示

这是一个**纯静态、零依赖**的界面原型，用虚拟数据模拟 TeamSync 最终产品的核心体验。  
不需要安装、不需要构建、不需要后端；双击 `index.html` 就能看。

![桌面预览](preview.png)

## 怎么打开

**方式一：直接打开**

双击 `index.html`，或把它拖进浏览器。

**方式二：本地静态服务器（可选）**

```bash
cd team-scheduler/demo
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> 页面没有 `fetch`、没有外部字体/图标库，`file://` 直接打开也能正常工作。  
> 剪贴板复制在部分浏览器的 `file://` 下可能被拦截，会自动降级为兼容复制；通知、持久化等能力不会真的触发。

## 能体验什么

| 区域 | 可操作 |
|---|---|
| 团队日历 | 月 / 周 / 日视图切换；上一页/今天/下一页；成员筛选；“只看我的” |
| 团队忙闲 | 右侧按成员显示本周忙碌程度；条形越高越忙 |
| 活动详情 | 点击事件查看时间、地点、参与者、RSVP 状态 |
| RSVP | 接受 / 待定 / 拒绝；状态与右侧“待回应邀请”同步 |
| 新建活动 | 填写表单；保存时自动检测参与者时间冲突 |
| 冲突提示 | “冲突演示”会预填一个与王可冲突的活动；可“调整时间”或“仍然创建” |
| 私密活动 | 陈一诺的私密安排对林知远只显示“忙碌”，不泄露标题/地点 |
| 任务看板 | 全部 / 我的 / 待办 / 进行中 / 已完成；勾选完成；新建任务 |
| 任务截止 | 任务截止日出现在日历“全天”行；完成/删除后消失 |
| 通知 | 铃铛弹层 / 通知中心；全部已读；点击通知跳到活动或任务 |
| 搜索 | 顶部搜索活动、任务、成员（`Ctrl K` / `⌘ K` 聚焦） |
| 团队成员 | 邀请码复制、成员卡、角色权限表、查看成员日程 |
| 团队设置 | 改团队名/描述、通知开关、重置演示数据、删除团队（仅提示） |
| 移动端 | 侧栏变抽屉 + 遮罩；周/日视图横滑；表单变底部弹层 |

## 60 秒演示路径

1. 打开页面，看周视图和右侧“团队忙闲”。
2. 点顶部 **“冲突演示”** → 直接点 **“创建活动”** → 看到“有 1 个时间冲突” → 点 **“仍然创建”**。
3. 点右侧 **“待回应邀请”** 里的“需求评审” → 点 **“接受”**，看状态和计数变化。
4. 左侧切 **“任务看板”** → 勾选一个任务 → 回到日历，看截止行变化。
5. 点陈一诺周四的斜纹“忙碌”块，看私密活动只显示时间段。
6. 缩到手机宽度，点左上角菜单，看抽屉 + 遮罩。

## 说明与边界

- **所有数据都是虚构的**：团队“软工大作业”、林知远/陈一诺/王可、活动、任务、通知均为演示数据。
- **项目组 2 人，演示团队 3 个账号**：3 个账号只是为了展示多成员 RSVP 和忙闲，不代表项目组人数。
- **刷新即重置**：没有后端、没有 localStorage、没有真实登录；这是视觉/交互原型，不是最终实现。
- **不覆盖真实能力**：通知不会真的发送，剪贴板/文件权限依赖浏览器，移动端只是响应式网页，不是 Capacitor 壳。
- 与正式文档的关系：本页用于确认“最终长什么样、交互是否顺手”；实现仍以 `docs/02`、`docs/03` 为准。
